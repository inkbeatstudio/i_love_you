# Букет для тебе

Сайт-подарунок: 3D-букет блакитних еустом, фото з ніжними словами, вірш, два відео і пісня «Очі».

## Як розмістити на GitHub Pages

1. Створи новий репозиторій на github.com (наприклад, `buket`). Можна зробити його публічним.
2. Натисни **Add file → Upload files** і перетягни туди **вміст** цієї папки: `index.html`, `README.md` і папку `media` з усіма файлами.
3. Натисни **Commit changes**.
4. Відкрий **Settings → Pages**. У розділі *Build and deployment* обери **Deploy from a branch**, гілку **main** і папку **/ (root)**, натисни **Save**.
5. За 1–2 хвилини сайт буде доступний за адресою `https://<твій-логін>.github.io/buket/`.

## Що де лежить

- `index.html` — увесь сайт. Тексти до фото, вірш і компліменти зібрані на початку скрипту в блоці «ВМІСТ», їх легко змінити.
- `media/photo-1.jpg … photo-9.jpg` — фото.
- `media/video-1.mp4`, `media/video-2.mp4` — відео (перекодовані з .mov, щоб грали на всіх телефонах).
- `media/ochi.mp3` — пісня.
